# BotHost Pro

Sito professionale per un servizio di hosting bot (Discord, Telegram, WhatsApp), servito con Python standard library.

## Avvio locale

```bash
python app.py
```

Apri `http://localhost:8000`.

## Endpoint disponibili

- `GET /`: landing page BotHost Pro.
- `GET /api/plans`: restituisce i piani hosting in JSON.
